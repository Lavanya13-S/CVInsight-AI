# CVInsight

A simple React + TypeScript app for managing candidates, screening resumes against a saved job profile, and comparing ranked results.

## Features

- Add candidates manually or upload resumes
- Parse resume text for skills and experience
- Save and switch between job profiles
- Run rule-based candidate screening
- View ranked candidate results
- Compare shortlisted candidates

## Getting started

1. Install dependencies:
   npm install

2. Start the app in development mode:
   npm run dev

3. Open the app in your browser:
   http://localhost:5173

## Build

To create a production build:

npm run build

## Type check

To verify TypeScript code:

npm run typecheck

## Notes

- Demo login is available in the app for quick access.
- Candidate data and job profiles are stored locally in the browser.
